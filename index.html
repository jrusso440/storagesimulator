Oracle Storage Simulator

Interactive teaching model: tablespace → datafile → segment → extent → block

Teaching simulation, not an Oracle engine. Blocks are fixed-size units; extents contain 8 contiguous blocks. Each row occupies one slot (4 rows per block). Deleted rows free slots but allocated extents remain reserved. This simplifies real Oracle behavior, including ASSM, high-water marks, and index internals.

Storage setup

All datafiles belong to the USERS tablespace. Each has 64 blocks; the first extent is 8 blocks.

Operations

Index allocation is modeled as 1 extent per index, independent of row count. Deleted rows do not automatically shrink segments.
